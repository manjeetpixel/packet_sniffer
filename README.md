# packet_sniffer
this is a very beginner level packet sniffer, which sniffs Ethernet level packet of all ports and prints that in hexadecimal form.

# Disclaimer
don't use it for unethical activities like sniffing packets in public networks, or sniffing packets in anyone's network without their permission. 

# Instructions for use
gcc sniffer.c -o sniffer
sudo ./sniffer
